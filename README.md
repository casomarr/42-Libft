# Libft

## Goal

Create a custom C library (libft) that includes a collection of useful functions, ranging from basic string manipulation to linked list operations. This library serves as a foundation for future C projects.

## Key Features

- Standard Functions: Reimplementation of standard C library functions (such asmemset, strlen, strdup and atoi).
- Additional Functions: Custom functions for string manipulation, memory allocation, and more (such asft_split, ft_itoa and ft_strjoin).
- Bonus Functions: Advanced functions for linked list manipulation (such as ft_lstnew, ft_lstadd_back and ft_lstclear).

## Challenges

- Correctness: Ensuring that each function behaves exactly like its standard library counterpart.
- Efficiency: Writing efficient code with minimal memory usage and optimal performance.
- Edge Cases: Handling edge cases like null pointers, empty strings, or invalid inputs.

## Skills Developed

- C Programming: Strengthening core skills in C, including memory management and pointer manipulation.
- Code Reusability: Building a library that will be reused across multiple projects.
- Testing: Writing and running tests to ensure the correctness of each function.

## Installation

1. **Clone the repository to your local machine:**
```sh
git clone git@github.com:casomarr/42-Libft.git
```
2. **Create a main function at the end of the file you want to test**
3. **Compile the project and run the program:**
```sh
make
./libft  
```
